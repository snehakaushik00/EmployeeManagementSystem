# EmployeeManagementSystem
Employee Leave Management System built using Java, Spring Boot, Spring Data JPA, Hibernate, and MySQL. Provides employee registration, login, employee management, leave application, and leave approval functionalities with REST APIs, DTOs, validation, exception handling, pagination, sorting, and basic authentication.


About the Project

The Employee Leave Management System is a backend application developed using Java and Spring Boot to simplify employee management and leave handling.

Employees can register, log in, and apply for leaves. Administrators can manage employee records, view leave requests, and approve leave applications.
